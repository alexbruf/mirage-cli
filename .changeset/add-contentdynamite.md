Add a fetch only Content Dynamite CLI (`ve-dynamite`) and its Mirage wrapper: profiles, ICP, categories, articles, batches, landing pages, image edit jobs, and uploads over the Dynamate v1 API. Token only auth via VE_DYNAMITE_TOKEN, no watch loops, billable calls report cost telemetry, and file flags read through the Mirage VFS bridge.
